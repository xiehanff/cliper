# Cliper Flutter 重构 — 功能差异报告

> 生成时间：2026-06-14
> 对比源：`D:\xiehan\github\cliper`（Electron 版）→ `D:\xiehan\flutter\cliper`（Flutter 版）

---

## 1. 完全缺失的功能

以下功能在 Electron 版中存在，Flutter 版尚未实现：

| # | 功能 | 旧版位置 | 影响评估 |
|---|---|---|---|
| 1 | **单实例锁** | `main.js:43-55` `requestSingleInstanceLock` | 用户可能同时启动多个实例，导致托盘图标混乱、剪贴板状态冲突。**建议优先补齐。** |
| 2 | **macOS Dock 隐藏** | `MacOSAdapter.js:9` `app.dock.hide()` | macOS 上 App 会出现在 Dock 中，与本产品「不驻留任务栏/Dock」的产品形态矛盾。 |
| 3 | **macOS 静默开机启动** | `MacOSAdapter.js:12-14` `openAsHidden: true` | macOS 开机自启动时会弹出前台窗口，违背「后台启动」预期。 |
| 4 | **macOS 关闭时保持运行** | `MacOSAdapter.js:16-19` | macOS 用户关闭窗口时应用直接退出，托盘消失。 |
| 5 | **毛玻璃效果** | CSS `backdrop-filter: blur(20px)` | 旧版容器和侧边栏有毛玻璃半透明效果，Flutter 当前为纯色背景。 |
| 6 | **设置面板文本未本地化** | — | "开机自启动"、"关闭" 为硬编码中文，未使用 `AppLocalizations`，切换英文后仍显示中文。 |

## 2. 功能不等价

以下功能双方均有实现，但实现方式或能力有差异：

| # | 差异点 | Electron 版 | Flutter 版 | 说明 |
|---|---|---|---|---|
| 1 | **Windows 文件剪贴板读取** | `CF_HDROP` / `FileNameW` 原生读取 | `super_clipboard` 插件 + MethodChannel 回退 | 插件在部分 Windows 版本上可能不可靠，回退路径未充分测试。 |
| 2 | **Windows 路径大小写归一化** | `normalizePathForProtocol` 统一小写 | 无路径归一化 | 去重时 "C:/Foo" 和 "c:/foo" 可能被视为不同条目。 |
| 3 | **窗口尺寸** | 660 × 720 | 780 × 720 | Flutter 已加宽。 |
| 4 | **分组颜色数量** | 6 种马卡龙色 | 7 种色板 | Flutter 多一种，不破坏兼容性。 |
| 5 | **设置面板内容** | 包含主题/语言/快捷键开关 | 仅含开机自启动 | 主题/语言/快捷键开关已放在顶部工具栏，属于布局差异非功能缺失。 |

## 3. Flutter 版改进项

以下为 Flutter 版优于 Electron 版的功能：

| # | 改进 | 说明 |
|---|---|---|
| 1 | **光标跟随窗口定位** | 优先在鼠标所在显示器居中，Electron 为固定屏幕居中。 |
| 2 | **图片尺寸标签** | 副标题显示 "PNG 1024×1024" 格式+尺寸。 |
| 3 | **分组名去重校验** | 大小写不敏感去重，Electron 无此校验。 |
| 4 | **平台感知快捷键显示** | macOS 显示 ⌘⌥⇧，Windows 显示 Ctrl+Win。 |
| 5 | **空状态本地化** | 中文/英文随语言切换。 |
| 6 | **写入失败静默降级** | 持久化异常被捕获并日志记录，不崩溃。 |
| 7 | **Esc 取消录制** | 录制态下按 Esc 退出，Electron 无此功能。 |

## 6. 已验证匹配的功能

以下功能双方实现一致，无需额外工作：

- 剪贴板监听（文件→文本→图片优先级）

- 深色/浅色主题切换
- 中文/英文国际化（17/19 键）
- 快捷键录制 + 平台友好展示
- 侧边栏 + 分组 CRUD + 颜色选择器 + 拖拽归档
- 托盘图标 + 右键菜单（显示/隐藏 + 退出）
- 三类条目渲染（文本/图片/文件）
- JSON 持久化 + 旧版数组格式兼容
- 短 ID 生成
